# Les Cendres de Valgris

Un action-RPG sombre en vue isométrique, pensé d'abord pour le téléphone, avec un univers original.

**Jouer :** https://martymart40.github.io/Cendres-de-valgris/

- Le jeu s'ouvre sans compilation : `index.html` charge `css/` et `js/` (base, catalogues, moteur, interface, démarrage).
- `npm test` roule le banc d'essai, le robot et le rendu en image.
- `CONCEPTION.md` décrit la vision, l'état du jeu, l'équilibre et la feuille de route.
